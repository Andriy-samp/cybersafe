# Landing Page: Кібербезпека (CyberGuard)

Проста семантична посадкова сторінка (Landing Page) на тему сучасного кіберзахисту та інформаційної безпеки.

## Особливості проєкту
- **Семантична верстка:** Використано правильні теги структури HTML5 (`<header>`, `<main>`, `<section>`, `<article>`, `<nav>`, `<footer>`).
- **Сучасне оформлення:** Стилізовано за допомогою CSS змінних (CSS variables), адаптивної сітки Flexbox та Grid.
- **Адаптивність:** Сторінка коректно відображається як на десктопних моніторах, так і на мобільних пристроях.

## Технологічний стек
- HTML5
- CSS3 (Custom Properties, CSS Grid, Flexbox)

## Як запустити проєкт локально
1. Завантажте або склонуйте цей репозиторій.
2. Відкрийте файл `index.html` у будь-якому сучасному веб-браузері (Chrome, Firefox, Edge, Safari).
